# Material icons

The `ic_*.xml` vectors in `android/app/src/main/res/drawable/` use the original Google Material Design icons, licensed under Apache 2.0. These resources restore the previous app's icon controls without adding an icon font or icon library to the APK.

Source: https://github.com/google/material-design-icons/tree/master/src

Icons: `navigation/arrow_back`, `navigation/refresh`, `action/settings` (filled and outlined), `content/undo`, `av/play_arrow`, `av/stop`, `action/check_circle_outline`, `file/cloud_off`.

The native light and dark theme palettes were generated from the original `#4F46E5` seed using Google's Material Color Utilities 0.3.0, Tonal Spot, default contrast. No JavaScript dependency is included in the Android project or APK.
