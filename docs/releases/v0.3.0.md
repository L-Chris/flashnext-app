# FlashNext 0.3.0

## 原生 Android 与包体优化

- Android 客户端迁移为 Kotlin + Jetpack Compose，公式使用系统 WebView，音频使用 Media3。
- arm64 安装包约 **2.24 MB**，相比此前约 19.93 MB 的优化版 Flutter 包减少约 **88.7%**；不再携带 Flutter 引擎和 Dart AOT 代码。
- 继续仅发布 `arm64-v8a`、`armeabi-v7a`、`x86_64` 三个架构包，不发布通用包。

## 学习体验

- 评分成功后优先从缓存队列切换下一张卡片，学习卡到期、撤销、后台返回等情况与后端重新对齐；退出复习后刷新首页统计。
- 移除复习页的剩余额度信息和底部进度条，修复卡片四个圆角的边框显示。
- 保留英日词卡、多读音分组、数学公式、音频顺序播放、自动显示答案和撤销功能；日语不展示罗马音。
- 正反面公式共用 WebView，等待字体就绪后启动自动行为；渲染失败时可显示原文并手动重试。
- 音频在后台、切卡、退出、耳机拔出或失去焦点时停止，避免焦点恢复后突然续播。
- 保留统一时区、牌组学习设置、FSRS 参数与手动训练、应用内更新；牌组设置在等待接口时也可点击外部关闭，未保存修改仍有保护。

## 安装与升级

- 版本 **0.3.0**，构建号 **10**；沿用原包名与固定签名，可直接覆盖安装，自动保留旧版保存的服务器地址。学习进度和设置继续保存在原后端。
- **普通 Android 手机（包括 Redmi K60）下载 `FlashNext-0.3.0-android-arm64-v8a.apk`。** 32 位旧机选择 `armeabi-v7a`，相应设备或模拟器选择 `x86_64`。
- v0.2.0 用户可在应用设置中检查更新；v0.1.0 用户请直接在本页下载对应架构 APK。校验值见 `SHA256SUMS.txt`。
- 学习内容仍需连接可访问后端的内网或 Tailscale，支持 Android 7.0 及以上。

## 验证

- 原生实现已通过 14 项单元测试、6 项 Android 15 模拟器测试，以及旧 Flutter 正式包到原生正式包的覆盖升级验证。
- 本轮完成模拟器验证，Redmi K60 真机复测待完成。
