# FlashNext 0.3.1

本版本替代已撤下的 v0.3.0，包含原生 Android 迁移、设置简化和完整的应用内更新流程。

## 原生 Android 与包体

- 使用 Kotlin + Jetpack Compose，公式由系统 WebView 渲染，音频使用 Media3。
- 工程统一为 `android/`，移除旧 Flutter/Dart 源码与配置，版本由 `android/version.properties` 独立维护。
- arm64 安装包约 **2.26 MB**，相比此前约 19.93 MB 的优化版 Flutter 包减少约 **88.7%**。
- 仅发布 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 三种架构包，不发布通用包。

## 设置与更新

- 服务器地址和时区共用一个“保存”按钮，移除“学习时区”标题及网络、共享时区提示。
- 同时修改服务器和时区时写入新服务器，失败保留草稿和原地址；仅切换服务器不会覆盖目标服务器时区。
- 启动时自动检查新版本，也可在设置中手动检查。确认更新后由 App 下载对应架构 APK，显示进度，校验通过后打开系统安装界面。
- 首次更新按系统提示允许安装未知应用，授权返回后继续安装；取消安装后可直接重试，避免重复下载。
- 安装前校验 SHA-256、包名、版本、签名和架构；忽略草稿、预发布及旧版本。Android 安装仍需用户确认。

## 学习体验

- 评分成功后优先使用缓存队列切卡，学习卡到期、撤销、后台返回等情况重新与后端对齐，退出后刷新首页统计。
- 移除复习页剩余额度和底部进度条，修复卡片四个圆角的边框。
- 保留英日词卡、多读音分组、数学公式、顺序音频、自动显示答案、撤销、牌组学习设置及 FSRS 训练；日语不显示罗马音。
- 公式等待字体就绪后启动自动行为；音频在切卡、后台、退出、耳机拔出或失去焦点时停止。

## 安装与升级

- 版本 **0.3.1**，构建号 **11**，沿用原包名和固定签名，可覆盖已有版本并保留服务器地址。学习进度和设置继续保存在后端。
- **普通 Android 手机（包括 Redmi K60）下载 `FlashNext-0.3.1-android-arm64-v8a.apk`。** 32 位旧机选择 `armeabi-v7a`，相应设备或模拟器选择 `x86_64`。
- 首次从旧版升级到本版，请下载本页 APK 并覆盖安装；后续版本可使用本版内置的下载与安装流程。校验值见 `SHA256SUMS.txt`。
- 支持 Android 7.0 及以上，学习内容需要手机能够访问后端服务器。

## 验证

- 20 项单元测试、Android Lint、三种 ABI 的正式构建及固定签名校验通过。
- 本轮 Android 15 模拟器 13 项测试通过，覆盖统一保存、下载校验、缓存恢复、权限返回续装和真实系统安装界面；未配置预览服务器的原有公式用例跳过。
- 此前已验证旧 Flutter 正式包覆盖升级到原生正式包；本轮未补测真机。
