# FlashNext 0.2.0

## 新功能

- 新增牌组学习设置：每日新卡/复习额度、日切点、音频自动播放、新卡立即显示答案和延迟显示答案。
- 时区移至统一「设置」弹窗，所有牌组共用；牌组设置支持点击外部关闭，并保护未保存的修改。
- 支持 Markdown 与数学公式、英日词卡展示、卡片正反面音频按顺序播放。
- 可查看本牌组 FSRS 参数、复习日志数及训练状态，并手动启动训练。

## 展示与体验

- 英语多读音默认展示各自词性、词义及时态说明；同用法的备选音标以“或”合并，修复美音误标为英音。
- 仅在读音说明完整覆盖系统释义时隐藏重复释义；补充释义、自定义笔记和日语内容保持完整。
- 内容和公式字体就绪后才开始答题计时；切入后台暂停倒计时，渲染失败时支持原文与重试。
- 改善音频焦点、中断、切卡与退出时的播放清理，防止迟到回调影响当前卡片。

## Android 安装与更新

- 版本为 **0.2.0**，构建号为 **7**；沿用原有包名与签名，可直接覆盖安装并保留应用数据。
- **普通 Android 手机优先下载 `FlashNext-0.2.0-android-arm64-v8a.apk`**，避免下载同时包含三套引擎的通用包。
- `armeabi-v7a` 适用于 32 位旧机，`x86_64` 适用于相应设备或模拟器。新客户端的应用内更新会优先选择适合当前设备的安装包。
- 本版不再构建或发布通用包；所有安装包校验值见 `SHA256SUMS.txt`。
- 从 **0.1.0 升级请直接在本页下载对应架构的 APK**。旧版更新检查依赖通用包；升至 0.2.0 后，后续应用内更新可按设备架构选择安装包。
- 学习内容仍需连接可访问后端的内网或 Tailscale；本次仅发布 Android。
