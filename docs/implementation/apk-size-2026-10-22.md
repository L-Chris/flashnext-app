# Android APK 体积分析

样本为 `cec36d2` 的 arm64 release 验证包，版本 `0.2.0`、构建号 `8`。ZIP 条目测量如下，单位为十进制 MB；Flutter 的构建日志按 MiB 显示，因此 20.91 MB 在日志中约为 19.9 MB。

| 内容 | APK 内字节 | MB |
| --- | ---: | ---: |
| Flutter 引擎 `libflutter.so` | 11,747,528 | 11.75 |
| Dart 应用与 Flutter 框架编译产物 `libapp.so` | 6,882,184 | 6.88 |
| Android DEX 代码 | 990,743 | 0.99 |
| Flutter 资源（包括图标、许可证和着色器） | 616,429 | 0.62 |
| Android 资源 | 413,186 | 0.41 |
| JNI / DataStore 原生库 | 138,512 | 0.14 |
| 其他元数据、ZIP 头、对齐及签名 | 120,156 | 0.12 |
| **APK 合计** | **20,908,738** | **20.91** |

引擎与 Dart AOT 产物合计占约 89%。这里只有 arm64-v8a 一种架构；当前 GitHub 构建已经按架构拆分，不包含通用包。英语/日语词库、卡片音频和 KaTeX 字体通过后端取得，没有捆入 APK。品牌 PNG 为 1254 × 1254、495,220 字节，优化图片只能影响较小的一部分。Android R8 代码与资源缩减、Flutter 图标树摇已在 release 构建中启用。

## 已接入的优化

按 [Flutter 官方建议](https://docs.flutter.dev/perf/app-size#reducing-app-size)，构建加入 `--split-debug-info`，不启用代码混淆、不改变功能或原生库压缩方式。固定签名、相同版本与构建号的对照结果：

| 内容 | 原包 | 分离调试信息后 |
| --- | ---: | ---: |
| `libapp.so` | 6,882,184 | 5,899,144 |
| 完整 APK | 20,908,738 | 19,925,698 |

共减少 983,040 字节，约 4.7%。引擎及其他原生库大小不变。对应 arm64 符号文件为 `app.android-arm64.symbols`，3,274,776 字节；它是用于还原堆栈的独立构建产物，不需要随 App 安装。

CI 会为所有 ABI 生成符号，并作为单独的 `flashnext-symbols-<版本>-<运行编号>` Artifact 保存 90 天。需排查更早版本时应提前备份对应符号；发布页仍只包含三个 APK 和 SHA256 校验文件。本次没有替换已发布的 v0.2.0 附件或创建新 tag。

本地复现：

```sh
flutter build apk --release --target-platform android-arm64 --split-per-abi \
  --build-number=8 --split-debug-info=build/qa/symbols-build8
```

若要用 `--analyze-size` 深入查看 Dart 包组成，另做一次单架构分析构建；当前 Flutter SDK 不允许它与 `--split-debug-info` 同时使用。上述 APK 分项来自实际 ZIP 条目的压缩后长度。

## 下载体积与安装占用的取舍

目前 `.so` 在 APK 中未压缩，Android 可以直接映射加载。压缩原生库可进一步减小下载文件，但安装时需要提取并额外保存原生库，增加安装后占用；见 [Android 官方说明](https://developer.android.com/guide/practices/page-sizes#update-packaging)。本次保留现有打包方式，因此没有用增加安装后占用的方式换取更小的文件数字。

对照包已通过 release 构建、包名 / 版本 / ABI 检查、签名验证及 ZIP 内容核对；工作流通过 actionlint。未改业务代码，没有重复运行业务测试，也没有连接手机完成本轮安装验证。
